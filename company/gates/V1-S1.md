## Scope control

- 한 번에 하나의 GLM model부터 검증한다.
- Provider-level check와 client gateway request를 서로 다른 증거로 취급한다.
- Availability 오류와 model quality 실패를 혼합하지 않는다.
- 실제 endpoint, key, model ID, raw prompt/response, internal hostname은 외부 Evidence에 기록하지 않는다.
- 실패를 우회하기 위한 CCR source/dependency patch를 먼저 하지 않는다.

## Remaining risks

- 사내 API의 실제 protocol, 권한, proxy/TLS 조건은 아직 검증되지 않았다.
- Provider `Check Connection` PASS만으로 local gateway, streaming, tools, Claude Code compatibility를 증명할 수 없다.
- Gemma는 GLM 최소 contract가 통과한 뒤 검증 범위를 결정한다.
